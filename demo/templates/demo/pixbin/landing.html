django-pixbin SDK

A comprehensive Django integration for the Pixbin Image API. Upload, transform, and serve images with ease.

View on GitHub Pixbin.net

Quick Setup

{# djlint:off #} 
# Install
pip install django-pixbin

# settings.py
INSTALLED_APPS = [..., 'django_pixbin']
PIXBIN_API_TOKEN = 'your_token_here'

# urls.py (upload and preview widgets)
path('pixbin/', include('django_pixbin.urls'))
{# djlint:on #}

Template Tags & Filters

Transform images directly in templates with tags like pixbin_thumbnail, pixbin_srcset, and more.

  • {% verbatim %} {% pixbin_thumbnail %} {% endverbatim %}
  • {% verbatim %} {% pixbin_transform %} {% endverbatim %}
  • {% verbatim %} {% pixbin_srcset %} {% endverbatim %}
  • {% verbatim %} {{ image|pixbin_url }} {% endverbatim %}
