PixbinImageUploadWidget + verify_exists

The browser asks Django for a presigned URL, uploads straight to S3, and posts back only the image UUID. The API token never leaves the server. On submit, verify_exists=True asks Pixbin whether that UUID is real before the form validates.

{# djlint:off #} 
from django_pixbin.forms import PixbinImageField, PixbinImageUploadWidget

class DirectUploadForm(forms.Form):
    title = forms.CharField(max_length=200)
    image = PixbinImageField(
        verify_exists=True,
        widget=PixbinImageUploadWidget(),
    )

# urls.py - serves the presigned URL and complete-upload endpoints
path('pixbin/', include('django_pixbin.urls'))

PixbinImageWidget in a ModelForm

The model PixbinImageField hands ModelForms (and the Django admin) a form field that uses this widget by default. It shows the current image and fetches a new preview when you paste another UUID.

{# djlint:off #} 
# models.py
class Image(models.Model):
    title = models.CharField(max_length=200)
    image = PixbinImageField()

# forms.py - no widget configuration needed
class ImageEditForm(forms.ModelForm):
    class Meta:
        model = Image
        fields = ["title", "image"]
